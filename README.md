# 德州托管助手（Chrome 插件）

给 River 德州（`https://47.243.178.16`）用的**自动托管机器人**。它读取你这一侧能看到的
牌桌数据（你的底牌、公共牌、底池、下注、对手动作），算出胜率和建议动作；
打开托管后，轮到你时会**自动帮你弃牌 / 过牌 / 跟注 / 加注**。

> ⚠️ 只在你有权使用托管的牌桌上使用。插件看不到对手的底牌，胜率是"按对手可能的牌型范围"估算出来的，
> 不保证每手都赢，只追求**长期**做出更划算的决定。

---

## 安装（加载到 Chrome）

1. Chrome 地址栏输入 `chrome://extensions` 回车。
2. 打开右上角 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择本项目文件夹。
4. 打开游戏页面（第一次访问 IP + HTTPS 会提示证书风险，点"继续访问"），
   再点浏览器右上角的插件图标，右侧弹出**侧边栏面板**。

> 改了代码后：回到 `chrome://extensions` 点插件卡片上的刷新按钮，**再刷新游戏页面**。

## 面板怎么看（从上到下）

| 区域 | 作用 |
| --- | --- |
| **顶栏** | 右边显示"已连接 / 重连中…"，表示面板和后台是否连上（断了会自动重连）。 |
| **托管状态卡** | 大开关 = 托管总开关（默认关）。下面一行字告诉你机器人现在在干嘛：等待轮到你 / 思考中 / 已出手 / 这一步没能托管（附原因）。 |
| **接下来（橙色）** | 机器人已经想好、但还没点下去的动作，比如"加注至 40"。**不同意就立刻关掉开关，这一步会被取消，由你自己操作。** |
| **机器人建议** | 不开托管也会显示：当前该做什么、为什么、对手大概拿什么牌。 |
| **牌面 + 胜率圆环** | 你的底牌、公共牌、听牌提示；赢 / 平 / 输的概率。 |
| **四格信息** | 当前牌型、对手人数、底池、要跟多少；下面的"跟注回本需胜率 X%"= 跟注至少要有多少胜率才不亏。 |
| **本场统计** | 出手次数、各动作次数、托管时长、估算盈亏。重置要**连点两次**确认。 |
| **最近动作** | 机器人最近点过什么，默认显示 5 条，可展开。 |
| **策略设置（可折叠）** | 见下一节。折叠时标题上会显示当前设置摘要。 |

> 盈亏数字是根据托管期间看到的筹码变化**估算**的，仅供参考，以站点显示为准。

## 策略设置

设置区按"翻牌前 / 翻牌后 / 对手 / 其它"分组，每个下拉框下面紧跟着它自己的一行说明。

- **策略档位**
  - 档位①·简单：只看胜率和底池赔率，好理解，适合对照。
  - 档位②·复杂判断（推荐，默认）：翻牌前按起手牌强度 + 位置决定开池 / 跟注 / 3-bet；
    翻牌后综合牌型、听牌、牌面湿度、对手下注大小收窄对手范围，再决定下注尺度。
  - 档位③：开发中，暂不可选。
- **翻牌前 · 入池意愿**（标准 / 积极 / 很积极）：看翻牌**费用很小**时，牌差一点要不要也去看一张。仅档位②生效。

  | 档位 | 费用上限 | 什么牌会去看 | 费用最多占剩余筹码 |
  | --- | --- | --- | --- |
  | 标准（默认） | ≤ 1 个大盲 | 中等以上的牌（如 Q5s、J8o） | 10% |
  | 积极 | ≤ 2 个大盲 | 除最差一批（72o、83o 这类）以外都看 | 6% |
  | 很积极 | ≤ 3 个大盲 | 几乎任何两张牌 | 8% |

  对子、同花连张、同花 A 这类"投机牌"不受牌力限制。面对 3-bet（对手加到 6 个大盲以上）时这一项**不起作用**，照样弃差牌；
  筹码很短时，因为"占剩余筹码"这条限制，也不会乱看。
- **翻牌后 · 打法倾向**（稳健 / 均衡 / 激进）：影响跟注门槛、是否半诈唬。仅档位②生效。
- **翻牌后 · 大牌下注**（标准 / 强势 / 最大化）：拿到强牌时最多下多少筹码。仅档位②生效。
- **对手 · 对手类型**（自动识别 / 随机 / 松 / 标准 / 紧）：对手越紧，算出的胜率越保守。
  - 自动识别（推荐，默认）：机器人边打边记，观察满 8 手后自动判断这桌偏松还是偏紧；没看够之前先按"标准"算。
  - 手动选了某一种：一直按你选的算，机器人不会自动改。
  - 下拉框下面那一行会写明"此刻实际按哪种对手在算"。
- **其它 · 自动开始下一手**：房主用，局间自动点"下一手"，受总开关管辖。

## 安全设计（为什么不会乱点）

1. **默认关闭**：必须你手动打开开关才会动手。
2. **拟人延迟 + 预告**：轮到你后随机等 1.2～3.5 秒再点，这段时间先在面板预告；期间关开关即取消。
3. **防重复**：同一局面只出手一次；局面卡住 8 秒没变才允许重试。
4. **能过牌绝不弃牌**：不用花钱的时候不会白白弃牌。
5. **加注三层保护**：策略层封顶（普通牌最多下筹码 1/3）→ 按站点给的最小 / 最大加注额夹准 →
   金额没成功填进输入框就**不点加注**，自动降级成过牌 / 弃牌，防止误全下。
6. **按钮认不准就放弃**：找不到按钮或数据不全，这一步跳过并在状态卡说明原因，交给你自己操作。

## 想调参数？

所有可调参数都集中在 [constants.js](src/common/constants.js)：

- `AUTOPILOT.ACTION_DELAY_MIN_MS / MAX_MS`：拟人延迟（也就是"预告"能看多久）。
- `AGGRESSION_PROFILES`、`VALUE_BET_PROFILES`：打法倾向和大牌下注的具体比例。
- `PREFLOP_ENTRY_PROFILES`：入池意愿三档的费用上限（几个大盲）、牌力门槛、占筹码上限。
- `OPPONENT_STYLES`：对手风格对应的牌型范围和决策偏移。
- `RANGE_NARROWING`：面对下注 / 加注时怎么估算对手的牌。翻牌后按"小注 / 中注 / 大注 / 在我下注后加注"四张权重表，
  给对手每种牌（中了三条、顶对、小对子、没中的空气、听牌……）一个"会这样下注的可能性"（0~1）。
  想让机器人面对大注**更舍得跟**，就调高表里 `none`（空气 / 诈唬）和 `weak_pair` 的数值；想更谨慎就调低。
- `ACTION_BUTTON_RULES`、`BET_INPUT_RULES`、`NEXT_HAND_BUTTON_RULES`：怎么认页面按钮（站点改版时改这里）。
- `PANEL_UI`：面板历史显示条数、重连间隔等。

## 常见问题

**Q：坐上牌桌了，面板还是空的（没显示牌和胜率）？**
A：刷新一次游戏页面（插件要在页面建立连接前注入）。

**Q：状态卡显示"这一步没能托管"？**
A：看后面的原因。多半是站点按钮文字 / 结构变了，按"想调参数"一节改按钮识别规则。

**Q：机器人老弃牌 / 太松？**
A：翻牌前弃得多，先把"入池意愿"调到"积极"；翻牌后的取舍看"打法倾向"。"对手类型"建议用"自动识别"。
档位②在多人底池会自动收紧，属正常现象。
