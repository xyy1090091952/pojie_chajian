# 德州数据审计器（Chrome 测试插件）

一个**仅供你测试自己线上德州游戏**的 Chrome 扩展。它把浏览器与你的游戏服务器
（`https://47.243.178.16`）之间的 **WebSocket / fetch / XHR** 流量镜像出来，
自动识别其中像"扑克牌"的字段，帮你判断服务器**有没有把不该下发的隐藏信息
（别人的底牌、未翻开的公共牌）泄露到客户端**。

---

## ⚠️ 先理解一个关键前提（很重要）

浏览器插件**只能看到服务器真正发给这个浏览器的数据**，不能凭空算出没发下来的牌。所以：

- **服务器安全** → 它只会把你自己的底牌发给你，别人的底牌、未翻开的公共牌
  **根本不出现在流量里**，插件也抓不到 → ✅ 说明这项测试通过。
- **服务器不安全** → 插件能抓到别人的底牌 / 未翻开的牌 → ❌ 存在信息泄露漏洞，
  要去**服务端**修复（不该发给客户端的隐藏信息，就不要下发）。

因此本插件的定位是**"客户端数据审计 / 抓包工具"**，这也是测自家游戏唯一诚实、可行的方式。

---

## 功能

- 实时镜像 WebSocket / fetch / XHR 全部收发数据，不影响游戏运行（只旁路复制）。
- 顶部两张汇总卡片：
  - **底牌（hole）**：抓到的所有底牌。
  - **公共牌 / 未翻开牌（board·deck）**：抓到的公共牌、牌堆/未发牌。
- 抓到"服务器下发的底牌 / 牌堆"时弹出**泄露提示**。
- 原始消息流：可按关键词过滤、只看服务器下发、展开查看原文。

## 安装步骤（加载到 Chrome）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择本项目文件夹
   `/Users/bytedance/Documents/trae_code/pojie_chajian`。
4. 安装成功后，右上角会出现插件图标。

## 使用步骤

1. 打开你的游戏页面 `https://47.243.178.16`（首次访问 IP + HTTPS 会提示证书风险，
   点"继续访问"即可——这是自签证书的正常现象）。
2. 点击浏览器右上角的插件图标，右侧会弹出**侧边栏面板**。
3. 正常进行游戏（发牌、翻牌…），面板会实时显示抓到的数据。
4. 重点看：
   - **「底牌」卡片**里是否出现了**不止你自己的两张牌** → 若有别人的，就是泄露。
   - **「公共牌 / 未翻开牌」卡片**里是否出现了**本应还没翻开的牌** → 若有，就是泄露。

> 提示：如果面板一直空白，刷新一次游戏页面即可（插件要在页面建立连接前注入，刷新能确保生效）。

## 常见问题

**Q：面板里什么牌都没抓到？**
A：有两种可能——(1) 恭喜，你的服务器很安全，没把隐藏数据发下来；
(2) 字段名不在识别规则里。可在 [constants.js](src/common/constants.js) 的 `KEY_HINTS`
里补充你服务器实际用的字段名（比如你的底牌字段叫 `myCards`，就把 `mycards` 加进去）。

**Q：抓到的内容是乱码 / 二进制？**
A：说明你的协议用了二进制编码（如 protobuf）。插件会标注为"[二进制 …]"。
这种情况需要知道你的编码格式才能进一步解析，可以告诉我你的协议细节。

**Q：改了代码后不生效？**
A：回到 `chrome://extensions`，点插件卡片上的**刷新按钮**，再刷新游戏页面。

## 项目结构

```
pojie_chajian/
├── manifest.json              插件清单（入口配置）
└── src/
    ├── common/constants.js    全局常量（通信通道、识别规则等）
    ├── data/
    │   ├── card-parser.js     数据层：从消息里识别"牌"
    │   └── message-store.js   数据层：消息存储（环形缓冲）
    ├── inject/interceptor.js  注入页面：劫持 WebSocket/fetch/XHR
    ├── content/content.js     桥接：页面数据 -> 后台
    ├── background/
    │   └── service-worker.js  后台：汇总、广播数据
    └── panel/                 侧边栏面板（界面）
        ├── panel.html
        ├── panel.css
        └── panel.js
```

> 仅用于测试你拥有/有权测试的服务。请勿用于未授权的目标。
